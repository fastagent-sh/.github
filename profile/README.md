## FastAgent

[FastAgent](https://github.com/fastagent-sh/fastagent) takes an existing agent definition and serves it in your app, on GitHub, in Telegram, through an HTTP API, or behind a custom channel — without rewriting the agent.

```bash
npm i -g @fastagent-sh/fastagent
fastagent init my-agent
cd my-agent
fastagent dev
```
